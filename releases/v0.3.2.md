# Docs describe machines by role

No behaviour change from 0.3.1.

- Docs and verification notes no longer name individual machines readers have
  never heard of. They say "the test machine", "the desktop" or "the remote
  host" instead.

## Install or update

Download both assets into the same directory:

```bash
sha256sum -c SHA256SUMS
tar -xzf yoohoo-0.3.2.tar.gz
cd yoohoo-0.3.2
python install.py install
```
