# Neutral names in tests and docs

No behaviour change from 0.3.0.

- Tests, fixtures and docs no longer name the maintainers' machines, private
  network addresses or home directories; they use placeholder host names and
  documentation addresses.
- Live desktop integration tests now opt in with `YOOHOO_TESTBED=1` instead of
  checking for one machine's host name.
- Bundled agent-window-resolver re-vendored from upstream `main` (the same code
  as 0.3.0, with the same cleanup in its fixtures).

## Install or update

Download both assets into the same directory:

```bash
sha256sum -c SHA256SUMS
tar -xzf yoohoo-0.3.1.tar.gz
cd yoohoo-0.3.1
python install.py install
```
