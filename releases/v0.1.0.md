# Yoohoo's debut ✨

Darling, your window would like a word.

Yoohoo gives Omarchy windows a soft, theme-aware breathing border, a gentle
notification pop, and a place in the bell menu—so you can get to them when
you're ready. Focusing or closing a window clears its attention.

## In this release

- Native Hyprland urgency plus conservative, application-independent desktop
  notification capture. No agent hooks or automatic notification activation.
- A 3.6-second breathing cycle with eased fades and a quiet interval.
- Bell menu, configurable sound, machine-readable attention list, and local history.
- Per-user installer/uninstaller with backups and preserved personal settings.
- Bundled default soft-pop sound with separate third-party licensing.
- Automated regression, staged install/reinstall/removal, and release-package checks.

## Install

Download `yoohoo-0.1.0.tar.gz` and `SHA256SUMS` from this release into the same
directory, then run as your desktop user:

```bash
sha256sum -c SHA256SUMS
tar -xzf yoohoo-0.1.0.tar.gz
cd yoohoo-0.1.0
python install.py install
```

See the included README for dependencies, settings, updates, and removal.
No need to clone the repository or install a development environment.

## Compatibility and known limits

Early release, validated on Lua-based Omarchy with Hyprland 0.56.2. Requires
Python 3.11+, the Omarchy shell, systemd user services, PipeWire, and the
documented D-Bus Python bindings. Not yet validated across Omarchy versions.

Ambiguous notification senders are skipped. Applications must emit a supported
signal. Border timing is shared with normal focus-border transitions. Service
restart clears pending entries; history remains and currently has no automatic
rotation. The bundled sound is not MIT licensed; see THIRD_PARTY.md.
