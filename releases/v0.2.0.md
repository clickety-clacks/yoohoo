# Pick your next window ✨

Yoohoo now supports keyboard cycling through windows waiting for attention.

- Generic `next` / `previous` actions open the menu or cycle through its entries.
- `accept` opens the selected window during a cycling session; `cancel` dismisses it.
- Tab/Shift+Tab and arrows cycle with wraparound and automatic scrolling.
- Selection stays on the same window when the list refreshes; a disappearing
  selection moves to the next surviving entry.
- Optional personal bindings can create a hold-modifier switcher: open on the
  first press, cycle on subsequent presses, accept on modifier release.
- README examples use Super+Tab, but **installation assigns no shortcuts**.
- Updated README and plugin descriptions explain the behavior without the old slogan.

## Install or update

Download both assets into the same directory:

```bash
sha256sum -c SHA256SUMS
tar -xzf yoohoo-0.2.0.tar.gz
cd yoohoo-0.2.0
python install.py install
```

Existing personal settings are preserved. Restarting the service clears pending
attention; history remains. See README for requirements and optional bindings.
The example replaces Super+Tab's workspace navigation only if you add it yourself.

Compatibility remains Lua-based Omarchy, validated on Hyprland 0.56.2. Standard
notification attribution remains conservative; ambiguous senders are skipped.
The bundled sound uses separate third-party licensing. See THIRD_PARTY.md.
